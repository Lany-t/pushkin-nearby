# Пушкин рядом

Интерактивная литературная карта Москвы: девять мест, связанных с Александром
Сергеевичем Пушкиным, — с цитатами, вопросами и сохранением прогресса.

Учебный проект (конференция «Инженеры будущего», 2026). Автор — Петухова Василиса Андреевна, 10И.

## Что это

- **Карта** — схема центра Москвы, нарисованная кодом: река, бульварное кольцо,
  сетка улиц. Без карт-сервисов, тайлов и ключей.
- **Девять мест** — от Арбата, 53 до Остафьева, с цитатой и вопросом к
  каждому. Восемь из них на карте, Остафьево стоит в списке: усадьба в 30 км
  южнее и в кадр не входит.
- **Прогресс** — хранится локально в IndexedDB, не уходит на сервер.
- **Офлайн** — service worker кэширует приложение целиком.
- **«Я рядом»** — геолокация открывает карточку места, когда вы к нему подходите.

## Запуск

Статические файлы, сборка не нужна. Достаточно открыть `index.html` через любой
локальный сервер (по `file://` модули и service worker не работают):

```
npx serve .
```

## Стек

Чистый JavaScript без фреймворков и сборщиков: ES-модули, IndexedDB, CSS-анимации.
Карта — SVG, построенный в `map.js`. Точки и текст — в `data.js`. Шрифты подключены
подмножествами в woff2 (кириллица, латиница, цифры и знаки интерфейса) —
полные TTF остаются рядом как запасной формат.
